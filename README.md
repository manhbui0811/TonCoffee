# ☕ TonCoffee

Phần mềm quản lý quán cà phê chạy trên Windows.

[⬇️ Tải bản mới nhất](https://github.com/manhbui0811/TonCoffee/releases/latest/download/TonCoffee.exe) · [Tất cả phiên bản](https://github.com/manhbui0811/TonCoffee/releases) · [Trang giới thiệu](https://manhbui0811.github.io/TonSoft/#TonCoffee)

## Tính năng
- Bán hàng nhanh theo bàn
- Quản lý kho nguyên liệu
- In hóa đơn, phiếu pha chế
- Báo cáo doanh thu theo ngày

## Yêu cầu
- Windows 10 hoặc 11, 64-bit
- RAM từ 4 GB, trống khoảng 500 MB ổ cứng
- Microsoft Edge WebView2 Runtime (Windows 11 và hầu hết Windows 10 đã có sẵn; nếu máy báo thiếu, tải tại https://developer.microsoft.com/microsoft-edge/webview2/)

## Cách dùng
TonCoffee là một file `.exe` duy nhất, không cần cài .NET.
1. Tải file `TonCoffee.exe`.
2. Đặt file vào một thư mục riêng, ví dụ `C:\TonCoffee\`.
3. Mở file. Nếu Windows báo chặn, chọn **Thông tin thêm → Vẫn chạy**.

## Kiểm tra file tải về
Mã SHA256 nằm trong phần mô tả của mỗi bản phát hành. Kiểm tra bằng PowerShell:

```
certutil -hashfile TonCoffee.exe SHA256
```
